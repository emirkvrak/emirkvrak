## Hakkımda

Backend geliştirme alanında **C# ve .NET** ekosistemine odaklanıyorum. REST API'ler, ilişkisel veritabanları ve Docker tabanlı geliştirme ortamları üzerine çalışıyorum; öğrendiklerimi projeler geliştirerek uyguluyorum.

Geçmişte Python ile görüntü işleme ve sensör verisi işleme projeleri geliştirdim. Bu çalışmalar sayesinde gerçek veriler üzerinde problem çözme ve bir fikri çalışan uygulamaya dönüştürme deneyimi kazandım.
