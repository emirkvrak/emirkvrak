## Hakkımda

Yazılım geliştirmeyi yalnızca kod yazmak olarak değil; problem çözme, doğru mimariyi kurgulama ve sürdürülebilir sistemler oluşturma süreci olarak görüyorum. Temiz kod, ölçeklenebilirlik ve kodun okunabilirliği benim için en önemli unsurlar.

- C# ve .NET Core kullanarak katmanlı mimariler (Onion Architecture) ve web uygulamaları geliştiriyorum.
- Python ile görüntü işleme ve otomasyon süreçleri üzerine gerçek dünya projeleri üretiyorum.
- Yeni teknolojileri keşfetmeyi ve kendimi sürekli geliştirmeyi seviyorum.
- Birlikte değer üreten projeler geliştirmek ve kariyer fırsatları için iş birliklerine açığım.
